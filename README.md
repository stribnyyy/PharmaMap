# PharmaMap

PharmaMap is a lightweight web application
designed to help pharmacy employees locate
medicines within customizable storage systems.

## Planned features

- Customizable storage hierarchy
- Medicine catalog management
- Medicine search
- Interactive cabinet visualization
- Responsive web interface
- User authentication
- Data import and export

## Technology stack

- Python
- Flask
- SQLite
- HTML, CSS, JavaScript

## Local installation

1. Create a virtual environment.
2. Activate the virtual environment.
3. Install dependencies:

   pip install -r requirements.txt

4. Run the application:

   python -m flask --app run run --debug

## Deployment

Target platform: PythonAnywhere.
